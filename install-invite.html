Einmal einladen – direkt in der App freigeschaltet

iPhone und Safari speichern den Zugang getrennt. Deshalb wird dein Einladungslink erst beim Öffnen der installierten App freigeschaltet.

  1. Öffne diese Seite in Safari (nicht im Messenger-Fenster).
  2. Tippe zuerst auf „Einladung sichern“. Damit bleibt der Link auch erhalten, wenn iOS ihn nicht ins Symbol übernimmt.
  3. Tippe auf Teilen → Zum Home-Bildschirm hinzufügen.
  4. Aktiviere Als Web-App öffnen und tippe auf Hinzufügen.
  5. Öffne Schmetterlinge über das neue Symbol: Die Einladung wird automatisch geprüft. Nur wenn iOS den Link verworfen hat, tippe dort einmal auf „Einladung übernehmen“.

Stattdessen nur im Browser verwenden Die Freischaltung gilt ausschließlich auf diesem Gerät. Die Einladung wird nicht in einer neuen Datenbank gespeichert. Einladungen können widerrufen werden.
