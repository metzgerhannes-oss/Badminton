# Zugriffsaudit v138

Angenommene Spielerlinks und App-Einladungen haben derzeit verschiedene Zugriffsumfänge. Sie dürfen nicht stillschweigend gleichgesetzt werden. Öffentlich belegte Sportergebnisse und tatsächlich private Inhalte sind getrennt zu behandeln. Der Datenexport muss vorhandene Berechtigungen wiederverwenden und darf keine zweite Freigabe verlangen. Änderungen an Serverrechten bedürfen einer eigenen technischen Prüfung.
